# Security Policy

## Supported versions

Security fixes are currently applied to the latest development branch. This project is in early development and does not yet publish a long-term support matrix.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Contact the project maintainers privately through the security contact configured for the official repository. Include:

- a clear description of the issue;
- affected versions or commits;
- reproducible steps that do not contain exploit payloads;
- the potential impact;
- any suggested mitigation.

Allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

## Scope

Security reports are especially valuable for scanner sandbox escapes, unintended code execution, network access during scans, path traversal, advisory integrity, and incorrect vulnerability classifications.
